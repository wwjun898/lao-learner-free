# 老挝语口语学习

一款面向中文用户的老挝语口语学习免费版，适合在老挝生活、工作、旅行和进行日常交流时使用。应用支持 Web/PWA 和 Android APK 两种运行方式，老挝文字使用 Phetsarath OT 字体。

当前版本：**V1.9.3**。

## 主要功能

- **主题词汇**：数字、货币、时间、日期、度量、形状、颜色、方位、风景、家庭、职业、医疗、人际关系、社交礼貌以及常用词类等。
- **实用对话**：按生活、工作、购物、交通、旅行、医疗、商务等主题整理中老对照对话，支持播放、跟读和加入翻卡复习。
- **场景练习**：保留场景分类，免费版提供空白练习框架。
- **翻卡复习**：按主题词汇、实用对话等来源及分类筛选重点词句，保留已有重点记录，掌握后可直接移出。
- **构词法**：提供免费样本，整理老挝语常见前缀、构词规律和例词，例词支持发音。
- **常用语块**：免费版展示前 20 条语块及例句，完整十二类内容后续开放。
- **数字计算器**：辅助数字、金额和报价场景，并支持老挝语发音。
- **语音功能**：支持老挝语播放、正常语速播放、语音跟读和 Android 语音识别。
- **学习统计**：记录词汇学习、播放、练习和翻卡复习进度。

## 技术栈

- React 19
- TypeScript
- Vite 8
- Tailwind CSS 4
- Capacitor 8
- Android SDK / Gradle
- Microsoft Edge TTS（Web 与 Android 新增词在线发音）

## 本地运行

环境要求：Node.js 20 或更高版本，以及 npm 或 pnpm。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可使用。

生产构建：

```bash
npm run build
```

## 网络说明

本地词汇、对话和学习记录可以离线浏览。未缓存的微软老挝语发音需要网络。

## 构建 Android APK

项目包含 Android Capacitor 工程。Windows 本地构建可以运行：

```bat
build-android.bat
```

成功后会在项目根目录生成 `lao-learner-v1.9.3.apk`。此脚本生成 debug 安装包，适合测试和内部安装。

正式打包运行 `./build-release.ps1`，生成 `lao-learner-v1.9.3-release.apk`（独立发布签名、关闭调试）和 `lao-learner-v1.9.3-upgrade.apk`（使用原测试签名，可覆盖旧测试版并保留学习数据）。正式包不能直接覆盖旧测试签名的安装包；已有用户应使用兼容升级包，不要为更换签名而直接卸载旧版。

发布密钥和随机密码保存在本机 `_release-signing/`，已被 Git 忽略。请将整个文件夹私下备份，勿上传或分发；后续正式版本必须复用此密钥，否则无法覆盖升级。脚本会复用已有密钥，不会每次重新生成。

## 数据存储

用户收藏、重点复习词汇、AI 解析结果和学习统计默认保存在当前设备的本地存储中。清除浏览器或应用数据后，这些内容可能会丢失。

## GitHub Pages

仓库包含 GitHub Actions 部署配置。将项目推送到 `main` 分支后，可以在 GitHub 仓库的 Pages 设置中选择 GitHub Actions 作为发布来源。

GitHub Pages 只托管静态页面，不运行本地 AI/TTS 服务。Web 版在线解析、造句和语音需使用配套本地服务；Android 版使用原生调用路径。
